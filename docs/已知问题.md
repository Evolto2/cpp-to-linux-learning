# 上游代码的已知边界

## 计算器

没有完整检查数字输入失败；失败后继续计算可能读取未有效赋值的变量。自动检查覆盖四则运算、除零和非法运算符，不代表非法数字已被妥善处理。上游 README 中编译文件名与实际文件名不一致，统一构建入口使用了实际路径。

## 学生信息管理

文本字段中的竖线没有转义；文件中部分损坏记录会被跳过；部分数字转换接受前缀；英文大小写搜索不能作为完整 Unicode 支持。EOF 时菜单处理不完整。保存失败时，内存变更与磁盘结果可能不一致。检查使用了正常英文记录，并验证重复编号、无效编号和持久化。

## Asio 回显示例

客户端输入上限为 1023 字节；异常信息与退出码并非严格一致。服务端会为连接创建分离线程，缺少连接数限制和完善的优雅退出。本轮仅做功能检查，没有测试吞吐量、压力、线程资源上限或真实硬件。原版服务端监听 IPv4 通配地址，本轮只通过 127.0.0.1 连接。

这些问题没有在 upstream 中静默修复；练习任务与文档明确区分原始行为和后续修改目标。所有测试通过仅指检查脚本列出的用例通过。
