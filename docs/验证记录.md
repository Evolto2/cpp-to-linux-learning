# 验证记录

## Windows 本机实测

在本机 Windows 上，使用 Clang 23.1.3、CMake 4.4.3 和 Ninja，从新的 build/windows 目录配置并编译，生成四个可执行程序，构建成功。

标准库检查脚本实际运行结果：23/23 通过。

- 源码快照：所有导入文件与 SOURCE.json 中 SHA-256 一致。
- 计算器：加、减、乘、除、除零、非法运算符，共 6 项。
- 信息管理：新增、重启读取、编号查询、姓名查询、重复编号、无效编号、修改、修改后重启读取、取消删除、删除、删除后空列表，共 11 项。
- TCP：服务端启动、官方客户端回显、UTF-8 回显、跨缓冲区数据回显、断开后重新连接，共 5 项。

原始结构化结果见 reports/windows-results.json，完整构建输出见 reports/windows-build.log，测试控制台输出见 reports/windows-tests.log。

CMake 在 Windows 探测 pthread 的若干尝试失败后，正确识别了系统线程支持并继续完成构建；这属于能力探测过程，不是最终构建失败。
