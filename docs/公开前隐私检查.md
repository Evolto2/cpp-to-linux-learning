# 公开前隐私检查

公开版本从新的提交历史开始，旧版本及其历史保留在独立的私有仓库中。

本轮检查与处理包括：

- 文档和日志中的个人电脑用户名、实际本机路径已替换为通用示例或占位符。
- 所有公开提交的作者和提交者均使用 GitHub 提供的 noreply 地址。
- 检查了常见令牌、云访问密钥和私钥格式，没有发现匹配项；这不是对所有可能秘密格式的穷尽证明。
- Word 核心属性未包含用户姓名或真实邮箱。
- 691 个上游源码文件与 SOURCE.json 记录的 SHA-256 一致，上游作者署名、许可与已公开联系方式原样保留。
- 匿名访问验证：公开仓库可访问，私有备份不可访问，旧提交不能通过这个新仓库的 API 访问。

公开仓库不包含原版本的个人邮箱提交历史，也没有复制原仓库的 Git 元数据或私有 CI 运行链接。
