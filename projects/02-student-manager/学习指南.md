# 02 学生信息管理

## 学什么

项目使用两个类：Student 表示一名学生，StudentManagementSystem 管理 vector 中的多名学生，并把记录存入文本文件。先学运行与基本数据流，再读输入校验细节。

上游：[isrargabol/C--Student-Management-System](https://github.com/isrargabol/C--Student-Management-System)，MIT 许可证，入口是 `upstream/main.cpp`。

前置知识：函数、引用、string、class 和 vector 的基本用法。遇到 nullptr、迭代器、lambda 或异常时，可以先看本指南对应路径，不必一次读完整个文件。

## 运行与第一条记录

先在仓库根目录编译。学生数据保存到当前工作目录的 students.txt，所以单独建立练习数据目录。

```powershell
Set-Location -LiteralPath 'C:\Projects\cpp-to-linux-learning'
& '.\scripts\build-windows.ps1'
New-Item -ItemType Directory -Force '.\practice\student-data' | Out-Null
Set-Location -LiteralPath '.\practice\student-data'
& '..\..\build\windows\student_manager.exe'
```

选择 `1` 新增，按提示输入编号 `1001`、姓名 `Alice Zhang`、年龄 `22`、院系 `Control`、GPA `3.6`。完成后选择 `2` 显示记录，选择 `6` 退出；再次在相同目录运行，记录仍应存在。

菜单：1 新增，2 显示，3 查询，4 修改，5 删除，6 退出。删除前会询问 Y/N。原项目 GPA 采用 0～4 的规则，属于示例业务设定。

Linux 下先在仓库根目录构建，然后建立数据目录并运行 `../../build/linux/student_manager`，工作目录规则相同。

## 分四轮读源码

1. 从 main → loadFromFile → menu 开始，只看启动、菜单和退出。
2. 看 Student 的字段、构造函数、get/set，再读 addStudent 和 displayAllStudents，理解一条输入怎样成为 vector 的一个元素。
3. 看 findStudentByRoll、searchStudent、updateStudent、deleteStudent，跟踪找到的对象和修改位置；vector 删除元素后，旧指针与迭代器不能继续使用。
4. 最后读 saveToFile 和 loadFromFile，理解 `编号|姓名|年龄|院系|GPA` 一行对应一条记录，以及 getline、find、substr、stoi/stod 的分工。

新增的数据流：菜单选择 → 读取并检查各字段 → 构造 Student → push_back → 保存所有记录。重启的数据流：读文件 → 拆字段 → 转成数值 → emplace_back → 显示菜单。

## 三个修改练习

先复制 upstream 到 `practice/student-manager`，再改副本；可以使用 `clang++ -std=c++17 -Wall -Wextra practice/student-manager/main.cpp -o practice/student-manager/student_manager.exe` 单独编译，并在 student-data 目录运行副本程序。

1. 增加按 GPA 排序显示：验收为准备三个不同 GPA，输出顺序正确；排序策略要明确，不无意改变保存顺序。
2. 增加统计：显示人数和平均 GPA；验收为零人时不除零，一人时平均值等于该人的 GPA，多人结果与手算一致。
3. 完善数据校验：拒绝姓名或院系中的 `|`，并拒绝年龄 `22abc` 这样的混合输入；验收为错误输入不改原有记录，重启后仍可正常读取。

## 常见报错与原版边界

- 看不到上次记录：检查本次工作目录，程序不会自动搜索其他目录的 students.txt。
- 保存失败：查看输出的错误，不要把内存中看到了新记录当成已保存成功。
- 原版以 `|` 分隔字段，没有转义规则；姓名和院系中不要输入这个字符。
- 原版大小写查询主要适合英文，不能据此承诺任意 Unicode 姓名都支持大小写匹配。
- 损坏的文件行可能被静默跳过；部分 stoi/stod 调用会接受数值前缀，更新并不是严格校验。
- 原版输入结束 EOF 的处理不完整，自动输入时最后应提供菜单 `6`，不要依赖关闭输入流退出。

掌握标准：能跟踪一条记录从键盘到 vector、再到文件的过程，并解释为什么重启时需要读取文件。
