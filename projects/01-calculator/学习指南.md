# 01 基础计算器

## 学什么

先看 `upstream/Console_calculator_program.cpp`，它只有一个 main 函数。当前目标是读懂变量、cin/cout、switch 和除零检查，不急着加图形界面。

上游：[Ruzgar-Kaan/CppBasic-Calculator](https://github.com/Ruzgar-Kaan/CppBasic-Calculator)，MIT 许可证。代码原样保留；上游 README 中的编译文件名和实际文件名不同，以下命令使用仓库统一构建入口。

## 在 VS Code 中运行

先打开仓库根目录，在 PowerShell 终端执行：

```powershell
Set-Location -LiteralPath 'C:\Projects\cpp-to-linux-learning'
& '.\scripts\build-windows.ps1'
& '.\build\windows\calculator.exe'
```

依次输入 `*`、`1.5`、`4`，每输入一项按回车。输出应包含 `result: 6`。程序算一次就退出，这是原项目的行为。

也可以输入已准备的示例：

```powershell
Get-Content -LiteralPath '.\examples\calculator-input.txt' | & '.\build\windows\calculator.exe'
```

## 阅读顺序与执行流程

1. 看 op、num1、num2、result：分别保存运算符、两个数和结果。
2. 看三次 cin：执行到这里时，程序等待输入；输入值写入对应变量。
3. 看 switch(op)：根据运算符只执行对应 case，break 结束该分支。
4. 看除法分支：num2 为 0 时显示提示，否则计算商。
5. 看 main 的 return：结束程序，返回状态。

执行流程是：输入运算符 → 输入两个数 → 选择运算 → 显示结果 → 退出。先手算结果，再对照程序输出；可以用 VS Code 断点观察 num1 和 num2。

## 三个修改练习

修改前先复制整个项目到自己的练习目录，不覆盖 upstream。原目录构建命令仍编译原版；练习副本应使用下面的独立编译命令。

```powershell
New-Item -ItemType Directory -Force '.\practice' | Out-Null
Copy-Item -LiteralPath '.\projects\01-calculator\upstream' -Destination '.\practice\calculator' -Recurse
clang++ -std=c++17 -Wall -Wextra '.\practice\calculator\Console_calculator_program.cpp' -o '.\practice\calculator\calculator.exe'
& '.\practice\calculator\calculator.exe'
```

复制命令只执行一次；已有练习目录时继续编辑，不重复覆盖。

1. 增加循环：算完询问是否继续；验收为连续完成两次不同运算，并能主动退出。
2. 拆分函数：把计算逻辑移出 main；验收为 main 保留输入和输出，四则运算与除零提示仍正确，能说明参数和返回值。
3. 检查输入失败：给数字位置输入字母；验收为显示错误并结束或重新输入，不打印未定义结果、不进入死循环。

## 容易卡在哪里

- 找不到 exe：先执行编译，再确认终端位于仓库根目录。
- 除法结果有小数：这里使用 double，不是整数除法。
- 保存后行为没变化：重新编译练习副本，运行对应目录的 exe。
- 原版没有完整检查 cin 失败，非法数字输入不在“已正确处理”的范围内，这是练习 3 要解决的问题。

掌握标准：不看代码说清 switch 选中了哪个分支，并独立完成上述至少一个练习。
